# One-Line Office Joke Laugh-Off

One original one-line joke about office life: the trust-fall exercise,
and the management that keeps dropping everyone anyway.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` validates the line (single line, 1–199 characters, not blank)
and writes it plus a trailing newline to `/output/entry.txt`.
